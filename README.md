# task26092940

检验结果重复分组与二次确认库（单进程内存实现）。

## 运行全部测试

```bash
python3 -m pytest tests -q
```

## 接口

- `upsert(record)`：新增或完整替换一条记录，每次成功调用均产生新修订。
- `remove(id)`：删除记录并立即更新分组。
- `inspect(id)`：返回当前组全部成员 ID、不透明 token、是否允许进入抽样复核。
- `confirm(token)`：确认整组可独立保留；过期 token 返回 `False` 且不改变任何状态。

## 设计要点

- 记录与键构成二部图，组即连通分量。键索引为 `(键类型, 检测项目, 键值) -> 记录ID集合`，
  只存集合不展开记录对，3 万条共享同一键时仅一个 3 万元素的集合。
- 合组：同一键下的记录必属同一组，每桶任取一个成员即可定位组；并到最大组上，
  只搬移较小组的成员，不重新遍历大组旧成员。
- 拆组：删除/改键只在受影响的旧组成员范围内做 BFS 重算连通分量，不触碰无关组。
- 确认状态挂在组对象上；任何成员的新修订、加入、删除都会撤销涉及组的确认，
  旧 token 从 token 表中删除，永久失效；未受影响的组 token 与确认保持不变。

## 复杂度

设 n 为记录总数，g 为受影响旧组的大小，k 为单条记录的键数（≤2）：

- `upsert`：新增 O(k)；合组时搬移较小组，摊还 O(小组大小)；改键先删后加，
  删除侧 O(g)（仅限旧组）。单个大组下追加成员为 O(1) 摊还。
- `remove`：O(g)，仅在旧组内 BFS 重算连通分量；无关组零开销。
- `inspect`：O(组大小)，用于返回全部成员；token 查找 O(1)。
- `confirm`：O(1)。
- 空间：O(n)，每条记录至多出现在 2 个键桶中，与重复对数量无关。
